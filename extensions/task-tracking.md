# Task tracking (optional proposal)

Use an existing local queue, GitHub Issues, Jira, or another tracker when a single next action no longer represents the backlog.

The tracker MAY own task priority and status; `HANDOFF.md` remains the immediate execution cursor. Link to the canonical task rather than duplicating its full description. If the tracker is offline, explicitly mark its status unverified. Never assume a tracker grants authorization to perform sensitive actions.
