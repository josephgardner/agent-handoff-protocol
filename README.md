# Agent Handoff Protocol

A proposed, tool-independent protocol for continuing work across agent sessions.

**Status:** V4 is under development. The normative draft is proposed in a pull request; nothing here is yet a stable V4 standard.

The design goal is simple: a local `HANDOFF.md` should be sufficient for safe continuity. Task trackers, Git, structured state, and validation are optional extensions.

See the forthcoming V4 draft pull request for the specification and examples.

Background: [Agent Session Protocol on algoplay.com](https://algoplay.com/agent-session-protocol/).
